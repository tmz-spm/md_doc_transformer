文書変換 — 完全オフライン・簡易版
================================

【使い方】
1. ZIPを右クリックし、必ず「すべて展開」してください。
2. 展開先の「index.html」をChromeまたはEdgeでダブルクリックして開きます。
3. Markdown / Word (.docx) / TeX (.tex)を入力します（MarkdownとTeXはプレビューが自動更新）。
   ソース欄でTabキーを押すとプレビューへ切替、プレビューでTabキーを押すと編集に戻ります。
   「ソース」「プレビュー」タブをクリックしても切り替えられます。
   入力欄ではTabキーは空白挿入ではなく表示切り替えになります。
   ファイルを作るときは「変換」を押します。
4. 「ダウンロード」で結果を保存します（プレビュー更新だけでは変換ファイルは作られません）。

Node.js、npm、バッチファイル、ネット接続、ローカルサーバーは不要です。
画面に「準備完了」と出れば起動成功です。
ブラウザだけで処理し、文書を外部送信しません。

【注意】
これはPandocエンジンを同梱した元のアプリではありません。
PandocのWebAssemblyバイナリを入手できなかったため、
「基本機能の簡易変換版」として作り直しました。数式処理用のJavaScriptライブラリはvendor/へ同梱しています。

主な対応項目：見出し、段落、太字、斜体、リスト、引用、簡単な表、
リンク、コード、基本TeXの節・リスト・数式文字列、画像（関連ファイルを指定）。

主な非対応・制限：
- Wordの基本的な数式（OMML）は読み書きできます。特殊な数式・独自マクロ・元の組版やソースの完全な再現には制限があります。
- Wordのレイアウト・段組み・改ページ・複雑な表の忠実な再現。
- Word参照スタイルの指定（画面で無効になっています）。
- TeXの独自マクロ、特殊パッケージ、複雑な数式の構文解析。
- すべてのMarkdown拡張、脚注の忠実な相互変換。
- Word旧形式 .doc は未対応。

Wordの読み込みには、ブラウザ側のZIP解凍機能（DecompressionStream）が必要です。
最近のChrome/Edgeでの利用を推奨します。

なお、書き出したWordは標準の.docx形式（ZIPストア方式）なので、
圧縮Wordよりファイルサイズが大きめになることがあります。
画像付きMarkdown/TeXは関連ファイルと共にZIPでダウンロードされます。

【ファイル】
index.html          起動画面（これをダブルクリック）
style.css           画面の装飾
engine-offline.js   変換エンジン（ブラウザ上のJavaScript）
app-offline.js      操作とファイル保存
README.txt          この説明書
NOTICE.txt          著作権・ライセンスについて

【トラブル時】
「準備完了」にならない場合は、ブラウザの開発者ツール（F12）の
Consoleに表示されるエラーを確認してください。

【プレビューと対応表の更新】
- 見出しの装飾的な下線を削除しました。明示した水平線だけを表示します。
- 変換後プレビューは生成した出力ファイルを読み直した内容を表示します。
- 下線（<u>文字</u>）、ハイライト（==文字==）、上付き（<sup>2</sup>）、
  下付き（<sub>i</sub>）をMarkdown・TeX・Word間で基本的に相互変換します。
- チェックリストの [x]/[ ] 記法の復元、およびWord内コード段落の読取を改善しました。
- Markdown形式の詳しい一覧は SUPPORTED_FEATURES.md を参照してください。

【2026-10-26 プレビューと自動挿入の監査】
詳しくは AUDIT_REPORT.md を参照してください。
- 見出し・引用・表のプレビュー装飾に、元の文書にない罫線や見出し色を足さないよう変更。
- Wordの表に見出し行・罫線の指定がなければ、Markdown出力は見出しを捏造せずHTMLの<table>として記録します。
  Word → Markdown → Wordの往復でも、明示されていない罫線・見出し行を挿入しません。
- チェックリストのチェック記号の前に、箇条書きの「・」を重ねないよう修正。
- Wordの非表示文字、フィールド命令、TeXのコメントを本文として表示しないよう修正。
- Wordに文字どおり書いた *** / --- / <u> などを、装飾として誤認しないよう修正。
- YAMLフロントマターを水平線として表示しない（Word/TeX出力では本文に含めず注意表示）。
- 画像ファイルが見つからなければ架空の「[画像: ...]」を挿入せず、元の画像記法を文字として保持し注意表示。
- この簡易版は Word / LaTeX のページ組版を再現するものではありません。

【数式対応の追加】
行内 $...$ と別行 $$...$$ を描画し、分数・平方根・添字・積分・総和・行列を編集可能なWord数式として出力します。Wordからの読込にも対応します。利用時はNode.js・ネット接続は不要です。サンプルから確認できます。
ライブラリの情報はNOTICE.txtとvendor/README.mdを参照してください。
