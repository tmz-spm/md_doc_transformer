# 文書変換

ZIPをすべて展開して、ChromeまたはEdgeで index.html を開きます。インストールやインターネット接続は不要です。docx・Markdown・TeXを相互に変換できます。

1. 入力形式を選び、ファイルを開くかソースを入力します。
2. MarkdownやTeXでローカル画像を参照している場合は、「オプション」の「画像・関連ファイルを追加」から画像を選びます。
3. 出力形式を選び、「変換」「ダウンロード」の順に押します。画像付きのMarkdownやTeXは文書と画像をまとめたZIPとして保存されます。

## 実行時に使う6ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | 画面と起動口。CSSとJavaScriptを読み込む。 |
| style.css | 画面の見た目を整える。 |
| app-offline.js | 入力、変換ボタン、プレビュー、ダウンロードを操作する。変換処理の入口は convert()。 |
| engine-offline.js | 3形式を共通のブロック配列に読み込み、指定形式へ書き出す。画像とZIPも処理する。 |
| vendor/math-libraries.js | 数式を画面に描き、TeXとWordの数式を変換する。 |
| vendor/katex.min.css | 数式の見た目を整える。必要なWOFF2フォント20種類をこのファイルに内蔵。 |

README.md はこの説明書です。NOTICE.txt と vendor/sources/mathml2omml.js はライセンス文書と同梱ライブラリのソースです。

## 主な対応範囲

見出し、段落、基本の文字装飾、単層リスト、引用、単純な表、リンク、コード、画像、数式に対応します。Word出力ではPNG・JPEG・GIFを埋め込み、TeX出力時はGIFを静止画PNGへ変換します。基本的な数式はWordの編集可能な数式形式（OMML）へ変換します。脚注、複雑なレイアウト、独自のTeXマクロなどには制限があります。
